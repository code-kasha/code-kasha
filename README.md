<p align="center"><b>Keep your momentum.</b></p>

[**sk8r**](https://github.com/code-kasha/sk8r) sets a project up so it actually runs: it works out what the project is, installs its dependencies, fills in local settings, adds run buttons to your editor and checks that the app really starts, all after one approval. It also keeps a short briefing up to date so the next AI session picks up where the last one stopped.

```bash
uv tool install sk8r
sk8r run --dry-run   # see the whole plan; nothing is written or run
```

Python 3.11+, standard library only at runtime · Linux, macOS, Windows · MIT · v1.0.1 on PyPI  
→ [Repository](https://github.com/code-kasha/sk8r) · [Website](https://www.akashdamle.in/sk8r) · [Write-up](https://www.akashdamle.in/projects/sk8r)
